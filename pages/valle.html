El Valle

Un conjunto de lugares pequeños, conectados entre sí, donde cada camino puede llevarte a una actividad, una persona o una historia.

Un pequeño recorrido

Un lugar para caminar sin prisa.

Cada lugar tiene su propio ritmo y una razón para volver. Algunos sirven para trabajar, otros para explorar, y muchos simplemente para encontrarte con alguien.

El Valle cambia

El mismo lugar nunca se siente exactamente igual durante todo el año.

El paso del tiempo transforma el paisaje, las actividades y las cosas que podés encontrar. La estación también cambia qué vale la pena sembrar, pescar o salir a buscar. Conocer el Valle es, en parte, aprender a leer esos cambios.
